# ツール — 思考・タスク整理アプリ

**「白紙に書く」のではなく「型(箱)を埋める」ことで、タスクの受け取りミスと思考の迷子をなくす、PCローカル完結の完全個人用アプリ。**

新規作成すると白紙ではなく目的別の箱が出る。埋まらなかった箱が「上司に確認すべきこと」として可視化され、記録がそのままタスク一覧になる。

設計の詳細は [`docs/思考タスク整理アプリ_たたき台v0.2.md`](docs/思考タスク整理アプリ_たたき台v0.2.md) を参照。

## 実装済み(Phase 1 / MVP)

| ID  | 機能           | 内容                                                       |
| --- | -------------- | ---------------------------------------------------------- |
| F1  | タスク受信箱   | タイトル + 4箱(目的/完成形/期限/疑問点)。疑問点は複数登録・1件ずつ解決 |
| F2  | タスク一覧     | 期限順。ステータス4段階。未解決の疑問が残ると「要確認」バッジ |
| F3  | 空雨傘メモ     | 事実/解釈/行動 の3枠。タスクへの紐付けは任意                |
| F4  | 提出前チェック | 3問。チェックは任意で、通さなくても完了にできる             |
| F5  | 保存とバックアップ | ローカルファイルに永続保存 + 全データのJSON書き出し/読み込み |

## 実装済み(Phase 2 / 3)

議事録テンプレ(決定 / TODO / 論点)、結論ファースト下書き、録音同期つき議事録(システム音声 + マイク。書いた行からその時点を聞き返せる)。

ブレストモード(時間制限 + KJ法)は一度作ったが、使わなかったので削除した。

AI壁打ち(Gemini)は**実装しない**方針にしたので、このアプリは一切通信しない。

## 動かす

```bash
npm install
npm run app     # 開発モード(ホットリロード付き)
```

普段使い用の実行ファイルを作る場合:

```bash
npm run exe     # src-tauri/target/release/app.exe を生成(インストーラなし)
npm run bundle  # NSISインストーラまで作る(ネットワーク制限下では失敗することがある)
```

### 必要なもの

- Node.js 20+
- Rust (rustup) — `winget install Rustlang.Rustup`
- Visual Studio Build Tools の C++ ワークロード — `winget install Microsoft.VisualStudio.2022.BuildTools`
- WebView2(Windows 11 には最初から入っている)

## データの保存先

```
%APPDATA%\jp.temmie0232.tool\data.json
```

- 通信は一切しない。データはこのPCから出ない
- 保存は一時ファイル経由で置き換えるので、書き込み中に落ちても既存データは壊れない
- PC乗り換えや事故に備え、バックアップ画面からJSONを書き出しておく

## キーボード操作(vim風の2モード)

入力が主用途なので、マウスなしで一周できるようにしてある。画面にボタン・タブは置いていない。編集画面は自動保存。

**vim と同じ「移動」と「入力」の2モード。**いまどちらかは画面左下に出る。

- **`-- 移動 --`** … 入力欄が読み取り専用になり、1文字のキーが全部ショートカットになる
- **`-- 入力 --`** … 欄に文字が入る。単キーのショートカットは効かない

`Esc` は**入力をやめるだけで、画面は動かない**。画面を出るのは移動中の `Esc`。書いている途中に一覧まで戻されることがない。

### 慣れると主役になる3つ

`j`/`k` は「近づく」動きなので、行数ぶんの時間がかかる。これらは**対象が何個あっても打鍵数が変わらない**。

| キー        | 動作                                                       |
| ----------- | ---------------------------------------------------------- |
| **`f`**     | 画面の押せるもの全部に札が出る。札を打つとそこを押す(2打鍵以内) |
| **`Ctrl+E`** | 会議が始まった瞬間。議事録を作る手順を飛ばして、その場で録音が始まる |
| **`Shift+F`** | 同じく札。押さずにそこへ移るだけ                         |
| **`/`**     | 名前の数文字で、全データから直接開く(件数が増えても同じ速さ) |

タスク一覧では詳細を開かずに `x`(完了 ⇄ 作業中)と `Ctrl+1`〜`4`(ステータス)が効く。往復が消える。`dd`(削除)も同じで、消したあとは次の行に乗っているので続けて消せる。

### 全体

| キー           | 動作                            |
| -------------- | ------------------------------- |
| `Ctrl+Alt+T`   | **呼び出す / 隠す(常駐中、他アプリからでも)** |
| `i`            | いまいる箱に書き始める(→ 入力)  |
| `Esc`          | 書くのをやめる(→ 移動)。もう一度でその画面を出る |
| `jk`           | 同じく → 移動(素早く続けて)。**日本語入力中は効かないので Esc** |
| `j` `k` / `gg` / `G` | 主なものを上下に辿る / 先頭 / 末尾(移動中) |
| `3j` / `5G`    | 数字を先に打つと回数 / 5番目へ  |
| `Tab`          | 細かいもの含めて次へ(札でも届く) |
| `Enter`        | 箱なら書き始める / それ以外は押す(移動中) |
| `Space`        | チェックの入 / 切(移動中)      |
| `x`            | 完了 ⇄ 作業中(タスク一覧で)   |
| `Ctrl+O` / `Ctrl+I` | 来た道を戻る / 進む        |
| `o`            | その画面の新規作成(一覧で)     |
| `dd`           | 削除(一覧は乗っている行 / 詳細はその1件)。1回目は名前を出して確認 |
| `t` `m` `r`    | タスク / メモ / 議事録の一覧    |
| `T` `M` `R`    | 同じものの新規作成(Shift+同じキー) |
| `,`            | 設定と行き来する                |
| `a` / `c`      | 追加欄へ入って書き始める / 確認文をコピー(タスク詳細) |
| `h`            | 一覧へ戻る(`Esc` でも可)       |
| `Ctrl+1`〜`4`  | ステータス / テンプレ / 種別(入力中でも効く) |
| `Enter` / `Shift+Enter` | 改行 / 次の箱へ(メモ・タスク。1行の箱はどちらも次の箱へ) |
| `Tab` / `Ctrl+Enter` | 次の箱へ / 即保存(入力中でも効く) |
| `Ctrl+E`       | **どの画面からでも、議事録を作ってすぐ録音を始める**(議事録の中では一時停止・再開) |
| `Ctrl+Shift+E` | 録音を終える(確定)             |
| `Ctrl+M`       | 最小化                          |
| `?`            | ショートカット一覧              |

## 常駐

通知領域に常駐し、閉じても終了せずに隠れるだけ。完全に終了するにはトレイアイコンを右クリック →「終了」。Windowsのログオン時に自動起動する(設定画面で切り替え可)。

ウィンドウはボーダレスで、上端の細いバーがタイトルバー兼用(掴んで移動)。二重起動は既存ウィンドウにフォーカスが移る。位置・サイズは記憶される。

### 開発ビルドと並べたとき

開発ビルド(`npm run app`)は本番と同時に常駐できる。データも別(`data.dev.json`)。見分けは:

- **名前が「ツール (開発)」**(Alt+Tab / タスクバー / トレイのツールチップ / トレイメニューの見出し)
- **掴む取っ手が琥珀色**(本番は灰色)
- **左下に「開発」**

## 構成

```
src/                React側(画面とロジック)
  types.ts          データモデル(Task / Memo / Meeting)
  storage.ts        Rustコマンド越しのファイル読み書き
  store.ts          アプリ全体の状態。変更のたびにファイルへ書き戻す
  lib/              モード(移動/入力)・ショートカット・日付・録音
  components/       枠 / 箱 / 入力欄 / ショートカット一覧
  pages/            画面(タスク・メモ・議事録・設定)
src-tauri/          Rust側(ウィンドウとファイルI/O)
  src/lib.rs        load_data / save_data / 録音ファイル / トレイ常駐
```
